# SaiVerse Digital Library

A multi-page front-end website for SaiVerse.

## Pages
- Home
- Genres
- Library
- Subscription Plans
- About Us
- Contact
- Reader

## Catalogue
6 genres × 10 books = 60 books.

## Founder
Mr. Sai Kumar. The uploaded founder image is stored at `assets/founder.png`.

## Run
Open `index.html` in a browser. For best results, use a local server such as VS Code Live Server.

Book covers use Open Library's public cover-image URLs, so internet access is needed for the cover images. A fallback placeholder appears if a cover cannot load.

## Production next steps
